# 하이브리드 산업 안전 수어 교육 키오스크 (Customizable Edge-AI Sign Language Learner)

'전국마이스터고 스타프로젝트 AI Competition' 출품작  
본 프로젝트는 청각장애인과 건청인이 함께 안전하게 소통하며 일할 수 있도록 돕는 실시간 수어 학습 기기입니다. 엣지 컴퓨팅(Edge Computing)과 로컬 AI 서버를 결합하여, **학교 실습실이나 산업 현장에 당장 필요한 '맞춤형 수어'를 관리자가 직접 3D 뼈대 데이터로 추가하고 학생들이 즉각적인 AI 피드백을 받으며 배울 수 있도록 개발**되었습니다.

## 1. 문제 정의 (Problem Definition)

**"생명과 직결된 산업 현장, 그러나 '안전 수어'의 국가 표준은 없습니다."**

* **현장 맞춤형 수어의 부재:** 기계, 용접, 건설 등 산업 현장마다 사용하는 위험 장비가 다릅니다. 하지만 기존 수어 번역기들은 대중적인 일상 단어만 제공할 뿐, "프레스 기계 비상 정지"와 같은 특수한 생명 직결 단어는 알려주지 않습니다.
* **현장 은어와 소통 단절:** 표준 수어가 없기 때문에 공장마다 임의로 만든 '그들만의 은어(바디랭귀지)'를 사용하며, 노동자가 이직할 때마다 안전 교육을 처음부터 다시 받아야 하는 치명적인 사각지대가 발생합니다.
* **우리의 해결책 (대체 불가능성):** 세상의 모든 단어를 얕게 아는 클라우드 번역기가 아닙니다. **관리자(선생님)가 우리 실습장에 딱 맞는 안전 수어를 직접 기계에 녹화(Teaching)해서 넣고, 학생들은 오프라인 엣지 환경에서 NPU와 로컬 LLM을 통해 정밀한 채점과 다정한 대화형 피드백을 받으며 완벽하게 훈련할 수 있는 '현장 맞춤형 수어 학습 플랫폼'**입니다.

## 2. 딥다이브 핵심 기술력 (Engineering Highlights)

학생들이 밑바닥부터 직접 구현한 본 프로젝트의 핵심 기술 4가지를 소개합니다.

1. **75차원 3D 벡터 기반 자체 DTW 알고리즘:** 
   단순 이미지 비교가 아닙니다. `MediaPipe`로 추출한 손가락 관절, 몸통, 머리의 3D 랜드마크에서 75개의 방향 벡터(Direction Vector)를 추출하여 30프레임으로 정규화한 뒤, 자체 구현한 DTW(Dynamic Time Warping) 알고리즘으로 시계열 동작의 정확도를 0~100점 사이로 정밀 채점합니다.
2. **NPU 비전 + 노트북 LLM의 투트랙 하이브리드 파이프라인:** 
   라즈베리파이의 Hailo-10H NPU에서는 **시각-언어 모델(`Qwen2-VL-2B`)**이 온디바이스로 구동되어 사용자의 손 위치(A~I 구역)를 1차로 정밀 분석합니다. 이 시각 정보와 DTW 점수는 내부망(IP 192.168.137.1)으로 연결된 **노트북 서버의 LLM(`Qwen2.5:3b`)**으로 전달되어, 3~4문장의 다정하고 전문적인 피드백으로 최종 생성됩니다.
3. **터치 키오스크용 커스텀 한글 오토마타 (Virtual Hangul Keyboard):** 
   OS 기본 키보드에 의존하지 않고, 라즈베리파이 터치스크린 환경에서 완벽하게 동작하는 초성/중성/종성 결합 논리(한글 오토마타)를 적용한 가상 키보드 클래스(`VirtualHangulKeyboard`)를 파이썬 GUI로 자체 개발했습니다.
4. **스마트 통합 런처 시스템:** 
   서버와 클라이언트의 기동 순서 문제를 해결하기 위해, 런처 스크립트(`run_kiosk.sh`)가 0.1초 단위로 5000번 포트를 폴링(Polling)하며 AI 서버 준비 상태를 스마트하게 감지한 후 즉각 GUI를 띄웁니다.

## 3. 핵심 모듈 및 6가지 제공 모드 (Features)

시스템은 철저하게 모듈화되어 프론트엔드(`a.py`), 데이터 구축 스튜디오(`truth_studio.py`), 하이브리드 서버(`vlm_server.py`)로 분리 구동됩니다.

1. **정답지 스튜디오 (Truth Studio):** 새로운 수어 단어를 추가할 때 사용합니다. 3초 대기 후 2초간 동작을 취하면 75차원 뼈대 좌표를 추출해 즉시 시스템 정답지(`JSON`)로 덮어씁니다. 전문가의 시연 영상(`.mp4`)도 자동 추출됩니다.
2. **학습 모드:** 화면에 나오는 전문가의 시연 영상과 수형 텍스트 설명을 보며 기본 동작을 눈으로 익힙니다.
3. **연습 모드 (NPU VLM 분석):** 카메라 앞에서 동작을 따라 하면 시스템이 뼈대 좌표를 DTW로 채점합니다. 동시에 NPU가 사진을 분석하여 "손을 가슴 쪽으로 너무 내렸습니다" 등 정밀한 시각적 자세 교정 피드백을 제공합니다.
4. **확인 모드 (7종 미니게임):** 지루한 학습을 막기 위해 '실전 동작 퀴즈, 이미지 매칭, 설명 매칭, 스피드 단어 맞추기, 초성 동작 퀴즈, 거꾸로 퀴즈, 무한 서바이벌' 등 총 7가지의 다이내믹한 평가 시스템을 완벽하게 구현했습니다.
5. **자율 모드 (로컬 LLM 번역):** 특정 단어를 선택하지 않고 카메라에 자유롭게 동작을 취하면, AI가 동작을 1/2/3순위로 유추한 뒤 "방금 하신 동작은 ~입니다"라며 자연스러운 음성(Edge-TTS)과 텍스트로 번역해 줍니다.
6. **AI와 대화 (STT + LLM 융합):** 마이크를 통한 연속 음성 인식(Speech-to-Text) 기술과 카메라 수어 동작 전송 기능을 융합했습니다. AI 어시스턴트와 대화하며, 수어 관련 질문을 던지고 즉각적인 피드백을 받는 심화 관제 모드입니다.

## 4. 사용 스택 (Tech Stack)

* **Hardware:** Raspberry Pi 5 (8GB), Hailo-10H AI HAT, USB 웹캠, 로컬 서버용 노트북
* **Software (GUI):** Python 3, PyQt5, OpenCV (영상 재생 및 분석), NumPy
* **AI & Vision:** MediaPipe (Holistic 3D 뼈대 추출), **Qwen2-VL-2B** (NPU용 비전 분석), **Qwen2.5:3b** (노트북 대화형 언어 모델)
* **ETC:** Edge-TTS / gTTS (음성 읽어주기 자동 폴백), SpeechRecognition (음성 인식), Flask (기기 간 비동기 통신)
